This directory defines the high-level concepts, business logic, and architecture of this project using markdown. It is managed by [lat.md](https://www.npmjs.com/package/lat.md) — a tool that anchors source code to these definitions. Install the `lat` command with `npm i -g lat.md` and run `lat --help`.

Ustam'ın bilgi grafiği — bölümler:

- [[urun]] — Ürün: amaç, kullanıcı akışı, diller ve platformlar
- [[mimari]] — Mimari: katmanlar, tek native kapısı, tipli hata, platform tablosu, yerel arka uç
- [[is-kurallari]] — İş kuralları: iş emri kodu, fiyat dökümü, canlı takip, önerilen sıralama
- [[izinler]] — İzinler: izin durumu, tek seferlik konum, iş akışına bağlı yerel bildirim
- [[veri]] — Veri: veri sözleşmesi, yerel depolama, KVKK veri hakları
- [[testler]] — Testler: hangi kural neyle ve neden test edilir
- [[gorevler]] — Görevler ve durum: ders görevlerinin repodaki karşılığı
