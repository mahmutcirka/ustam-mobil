# Kaynaklar

Ustam geliştirilirken başvurulan tasarım ve teknik kaynaklar.

## Tasarım, Düzen ve Tipografi

| Kaynak | Kullanıldığı yer |
|---|---|
| [Figma — Design basics](https://www.figma.com/resource-library/design-basics/) | Renk, hiyerarşi ve boşluk kararları ([`branding.md`](branding.md)) |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) | Alt sekme çubuğu, dokunma hedefleri (≥ 44px), güvenli alan |
| [Apple HIG — App icons](https://developer.apple.com/design/human-interface-guidelines/app-icons) | `app-icon.svg` tasarımı ve ikon boyutları |
| [Apple HIG — Layout](https://developer.apple.com/design/human-interface-guidelines/layout) | Breakpoint ve kenar boşlukları ([`mimari-agac.md`](mimari-agac.md)) |
| [Apple HIG — Typography](https://developer.apple.com/design/human-interface-guidelines/typography) | Sistem yazı tipi yığını ve yazı ölçeği |
| [Material 3 — Typography](https://m3.material.io/styles/typography/overview) | Başlık / gövde / etiket ölçeği |
| [MDN — Responsive design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) | Media query'ler, grid ve `max-width` |
| [MDN — CSS logical properties](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_logical_properties_and_values) | RTL (Arapça, Farsça) uyumlu stiller |
| [WCAG 2.1 — Contrast (Minimum)](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html) | Renk token'larının 4.5:1 kontrast kontrolü |
